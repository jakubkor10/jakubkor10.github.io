# [Jakub Korpanty | Portfolio](https://jakubkor10.github.io)

## Description
Personal portfolio website built with HTML, CSS, and JavaScript. Constructed with the use of an AI agent . Features:

- Dynamic GitHub projects - Automatically fetches 2 latest repositories from GitHub API 
- Responsive design

## Features
- Fetches projects automatically from GitHub API
- Experience section indicates openness to new opportunities
- Personalized hero section, about me, and contact information
- Scroll-activated navbar styling
- IntersectionObserver animations for project cards

## Built With

- CSS3 (custom properties/variables)
- JavaScript (ES6+)
- Google Fonts (Inter)
